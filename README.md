# EV충전 기록 Auto

충전기를 꽂고 뽑기만 하면 차가 스스로 충전을 기록하고, 영수증도 알림도 없는 **아파트 충전까지 빠짐없이** 잡아내며, 금액은 **영수증·관리비 고지서와 원 단위까지** 맞춰 주는 Pleos Connect 차량용 충전 가계부입니다.

## 핵심 기능

| 기능 | 동작 |
|---|---|
| 아파트 충전 누락 방지 | 시동 끄기 직전 SOC·주행거리를 저장 → 다음 시동 때 비교. 주행거리 그대로 + SOC 상승 = 충전. 충전 중 앱이 꺼져 있어도 기록 |
| 공용 충전 자동 기록 | 충전 상태·SOC·충전 출력으로 시작·종료 감지, 내비 목적지 충전소 이름·정격 출력으로 사업자와 완속/급속/초급속 판정. 충전 출력을 알려 주지 않는 차종은 SOC 상승 속도(평균 출력, 최대 출력의 하한)로 급속을 가려 집 완속으로 오판하지 않는다 |
| 단가 4단계 | ① 이 충전소 확인 단가(처음 간 충전소에서 영수증·충전기 화면 단가 1회 입력 → 충전소·출력 구간별 저장, 다음부터 자동) ② 내 설정 단가 ③ 같은 사업자·같은 출력 구간 다른 충전소 확인 단가("지난번처럼 ○○원으로 할까요?") ④ 공시 안내가(무공해차 통합누리집 102개 사업자 × 출력 5구간 × 회원/비회원). 단가 출처를 화면에 표시, 공시 요금 갱신 시 재확인 안내 |
| 말로 단가 입력 | 충전이 끝나면 "이 충전소 단가를 말씀해 주세요" → "삼백팔십오 원" → "100에서 200킬로와트 충전기, 385원으로 저장할까요?" → "응". 출력 구간은 차가 이미 알아서 묻지 않고, 사업자 요금이 구간마다 달라 갈릴 때만 "충전기 출력이 몇 킬로와트인가요?"를 묻는다("백 킬로와트 사백십 원"처럼 한 번에 말해도 된다). 주행 중에도 손 안 대고. Pleos SpeechToText/TextToSpeech(ON_DEVICE). Gleo AI 호출("글레오, 충전기록에 SK일렉링크 100킬로와트 391원 저장해 줘")도 지원(assets/schema.json, 승인 후 활성) |
| 출력 구간별 단가 칸 | 사업자·충전소마다 5구간(완속 / 30~50 / 50~100 / 100~200 / 200kW 이상) 칸을 두고 공시가를 옆에 보여 준다. 말·영수증으로 들어온 단가는 그 충전 구간 칸 하나에만 넣는다(구간·충전기별 프로모션이 있을 수 있어 공시 요금이 같은 이웃 구간에도 넣지 않는다) |
| 충전소 구분 (GPS + 이름) | 같은 사업자라도 충전소마다 단가가 다르다(예: 집 근처 345원, 여행지 430원). 충전한 위치의 GPS와 충전소 이름(내비 목적지 → 없으면 주소 → 사용자가 붙인 이름)으로 충전소를 구분해 충전소별 단가를 따로 쓴다. 같은 자리라도 사업자가 다르면, 가까워도 이름이 다른 두 충전소면 다른 충전소로 본다 |
| 처음 간 충전소 단가 확인 | 같은 사업자·같은 출력 구간의 다른 충전소에서 확인한 단가가 있으면 그 값으로 계산하고 "지난번 ○○점처럼 420원으로 할까요?"라고 화면·음성으로 묻는다. '맞아요'(또는 "응") 한 번이면 이 충전소 단가로 저장, 다르면 금액만 말하거나 숫자로 고친다. 출력 구간이 다르면(50kW ↔ 100kW) 제안하지 않는다 |
| 자주 가는 곳 이름 | 확인 카드의 '이름 붙이기'(기록 상세·설정 → 충전소 단가의 '이름')에서 회사·부모님 댁·처가·시댁·마트·백화점·헬스장·학원 근처·단골 휴게소·캠핑장을 눌러 바로 이름을 붙인다. 같은 자리(GPS)·같은 사업자 충전소에 모두 적용되고, 기록·통계에 그 이름으로 보인다. (선택) 요금을 받지 않는 충전소는 같은 화면에서 '무료 충전소'를 켜면 0원으로 기록하고 단가를 묻지 않는다 |
| 지난 기록 보존 | 단가가 바뀌어도 지난 기록은 그때 단가 그대로(어제까지 190원·오늘부터 250원이면 어제 기록은 190원). 단가가 비어 있던 기록만 채운다. 설정 단가를 바꿀 때 지난 기록 금액이 달라질 상황이면 "단가가 바뀐 건가요, 잘못 입력한 건가요?"를 묻고, 잘못 입력한 경우에만 지난 추정 기록도 고친다. 영수증·관리비로 확정한 금액은 어떤 경우에도 그대로 |
| 처음 설정 | 처음 열면 집 충전 방식(아파트 관리비 / 집에 단 사업자 충전기 / 집 충전 안 함)과 아파트 단가를 받는다. 아파트 충전은 영수증이 없어 단가 없이는 금액을 계산할 수 없기 때문(추측하지 않는다) |
| 통계 | 이번 달(전월 같은 기간 대비·이달 예상), 월별 충전비 막대·평균 단가, 사업자별·충전소별(GPS로 묶음, 가장 저렴한 곳 표시)·충전 방식별, 차가 잰 실측 충전 속도, 최저·최고 단가 기록, 충전 누락 점검 |
| 내연기관차 대비 절약 | 주행거리를 차에서 자동으로 받아 따로 입력 없이 누적·이번 달 절약액, 1km당 전기·연료 비용, 실주행 전비를 계산. 비교 기준은 차급(경차·준중형·중형·SUV·대형·하이브리드)을 고르거나 연비(km/L)를 숫자로 넣고, 연료 가격(원/L)을 넣는다 |
| 가는 충전소 예상 충전비 | 내비(NaviHelper)가 충전소로 안내 중이면 충전 계획(도착 SOC → 목표 SOC) × 배터리 용량 × 손실계수 × 그 충전소 단가(확인 단가 → 내 설정 → 같은 사업자 다른 충전소 → 공시가)로 "시청점에서 80%까지 채우면 약 16,256원"을 홈에 띄우고 한 번 읽어 준다. 단가를 모르면 금액은 비워 두고 충전 후 한 번만 알려 달라고 한다 |
| 이번 주행 비용 | 이번 주행 거리 ÷ 전비(차량 값, 없으면 충전 기록으로 구한 실주행 전비) × 내가 실제로 낸 평균 단가(최근 90일 결제액 ÷ 충전량) → "이번 주행 42km, 전기 요금 약 3,005원 · 내연기관차라면 5,950원". 목적지에 도착하면 읽어 준다 |
| 음성 안내 | 충전 기록("꺼져 있던 동안 집에서 충전한 것을 찾았어요. 32킬로와트시, 약 9,000원으로 기록했어요"), 예상 충전비, 도착 시 주행 비용, 달이 바뀐 뒤 첫 시동 때 지난달 충전비·전월 대비·절감액 브리핑. 말로 입력하는 중에는 끼어들지 않고, 설정에서 끌 수 있다 |
| 기록 속 충전소로 길안내 | 통계의 충전소별 목록에서 '길안내' → 차 내비로 목적지 전달(NaviHelper.requestRoute). Gleo: "글레오, 충전기록에서 제일 싼 충전소로 안내해 줘"(가장 저렴했던·자주 가는·지난번·이름) |
| 공공데이터 (키가 있을 때) | 한국환경공단 충전소 정보로 내 충전소의 공식 이름·운영기관·최대 출력과 지금 빈 충전기 수(급속/완속), 오피넷 전국 평균 유가로 내연기관 비교의 연료 가격 채우기. 위치는 보내지 않고 시·도 목록을 받아 기기 안에서 내 충전소 주변만 남긴다 |
| 영수증 = 확정 금액 | 차량 계산값은 '추정'. 영수증 금액(절사·반올림 반영된 최종값)이 들어오면 다시 계산하지 않고 그대로 대체 |
| 관리비 고지서 정산 | 월 충전 요금을 그달 아파트 기록에 충전량 비율로 배분(최대 잔여 배분) → 합계가 고지서와 원 단위까지 일치 |
| 손실계수 학습 | 영수증 충전량 ÷ 배터리 측 에너지로 충전방식별 손실계수를 학습해 추정 정확도 개선 |
| 실시간 요금 미터 | 충전 중 '지금까지 약 ○○원 · 목표 SOC까지 ○분, ○원' |
| 주행 안전 | 주행 중(UX 제한)에는 요약만 표시, 확인·입력은 정차 중 |
| 백업 | 기록·단가 설정을 JSON 백업 파일로 내보내기 |

## 단가 정확도 전략

충전 요금은 사업자·회원 여부·출력 구간(2026-08 개편 5구간)·현장 프로모션에 따라 kWh당 230~490원까지 차이 난다. 금액이 틀리면 가계부의 의미가 없으므로 다음 원칙을 둔다.

1. **현장 단가가 정답** — 처음 간 충전소에서 영수증(또는 충전기 화면)의 kWh당 단가를 한 번만 입력하면 그 충전소·출력 구간의 확인 단가로 저장한다. 같은 사업자도 충전소마다 단가가 달라(지역·충전소별 요금은 공시표에 없다) 확인 단가는 충전소 단위로 둔다. 충전소는 GPS 좌표 + 이름으로 기록하고, 같은 충전소인지는 이름이 같거나 위치가 150m 이내인지로 본다(사업자가 다르거나 내비 이름이 서로 다르면 다른 충전소). 이름이 없으면 기기 주소 변환(Geocoder)으로 도로명 주소를 붙이고, 설정·기록 화면에서 이름을 직접 붙일 수 있다. 영수증 입력 시 단가·충전량이 있으면 자동으로 확인 단가가 된다.
2. **처음 간 곳도 근사값** — 무공해차 통합누리집 '전기차 충전요금 안내'의 사업자별 요금 매트릭스(102개 사업자, 출력 5구간, 회원/비회원, 사업자별 갱신일)를 `core/src/main/resources/tariff/`에 스냅샷으로 넣어 둔다. 현재 요금 정보 공식 오픈 API는 없어 스냅샷을 정기 교체하고, 공공데이터 개방 요청을 병행한다(웹 화면을 앱에서 긁어 오지 않는다).
3. **출력 구간** — 같은 사업자도 구간마다 요금이 다르다(SK일렉링크 회원가 30~50kW 295원, 50kW 이상 391원). 정격(내비 maxChargingPower)을 알면 정확, 모르면 차량이 받은 최대 출력을 하한값으로 구간을 추정한다. 하한값일 때만 상위 구간 요금으로 보완한다.
   - 단가를 받으면 어느 구간 칸인지 `TierPlanner`가 정한다: ① 사용자가 말한 출력("백 킬로") ② 차가 확실히 아는 구간 ③ 후보가 여럿이면 입력 단가와 공시가가 같은 구간이 하나뿐일 때 그 구간(채비 410원 → 50~100kW) ④ 그래도 갈리면 충전기 출력을 묻는다 — 공시가로 후보를 좁혀서(채비 430원 → 100~200 / 200 이상), 화면에서는 버튼.
   - 단가는 언제나 구간 칸 하나에만 넣는다. 구간·충전기별 프로모션이 있을 수 있어, 공시 요금이 같은 이웃 구간이라도 따로 확인한다. 영수증처럼 되물을 수 없는 입력은 구간이 하나로 정해질 때만(또는 사용자가 출력을 고를 때만) 충전소 단가로 저장한다.
   - 충전소 확인 단가는 다른 구간 값을 빌려 쓰지 않는다(50kW 충전기 단가를 100kW 충전기에 쓰지 않음). 구간이 하한값이면 그 이상 구간에 확인한 값이 하나일 때만 쓴다.
4. **오래된 단가 감지** — 확인 단가를 받은 뒤 그 사업자의 공시 갱신일이 더 최근이면 '요금 변경 확인 필요'를 표시한다.
5. **추측하지 않기** — 관리비 청구 아파트는 공시 요금으로 추정하지 않고 사용자 단가 또는 관리비 고지서 정산으로만 확정한다. 단가를 모르면 금액을 비워 두고 입력을 안내한다. 집 반경 안이라도 급속 충전은 아파트 급속 단가를 넣지 않은 한(또는 내비 충전소 이름이 있으면) 집 근처 공용 급속으로 본다.
6. **최종값은 영수증** — 영수증 금액이 들어오면 절사·반올림된 그대로 확정하고 다시 계산하지 않는다.
7. **지난 기록은 그때 단가** — 기록마다 계산에 쓴 단가와 출처를 남기고, 단가 설정이 바뀌어도 지난 기록은 다시 계산하지 않는다(`RepricePolicy`). 다시 계산하는 경우는 ① 단가가 비어 있던 기록 ② 같은 충전소에서 아직 확인하지 않은 기록에 그 충전소 단가를 알려 줬을 때 ③ 공시가로 짐작한 미확인 기록의 회원/비회원 기준을 바꿨을 때 ④ 사용자가 "잘못 입력했다"고 고른 경우뿐이다.
8. **처음 간 충전소는 짐작 + 확인** — 단가 순서: 이 충전소 확인 단가 → 내 설정 단가 → 같은 사업자·같은 출력 구간 다른 충전소 확인 단가(가장 최근) → 공시 안내가. 이 충전소 확인 단가가 아니면 "○○원으로 할까요?"라고 확인받는다(같은 사업자도 충전소마다 다를 수 있어 그대로 믿지 않는다).

- **오피넷 무료 API** 전국 평균 유가(`avgAllPrice.do`) — 선택. `local.properties`에 `opinet.key=…`
- **CarUxRestrictionsManager** — 주행 중 UX 제한
- **위치** — Android LocationManager(충전소 구분·집 충전기 인식, 기기 밖으로 보내지 않음). Pleos FusedLocation SDK는 현재 문서상 'Not Available Yet'(저장소 미공개)이라, 공개되면 이 SDK로 바꾼다

## 시연 시나리오 (Virtual Console)

Virtual Console(2.1.0)의 Energy 항목은 Battery SOC·Battery Energy·Charge Switch·Charge Port입니다. 충전 상태·포트 연결 신호가 없어서 앱은 **주행거리 그대로 + SOC 상승**으로 충전을 판정합니다(실차에서 충전 상태 신호가 실제로 바뀌는 것을 확인하면 그 신호를 우선 사용). Battery SOC와 Battery Energy는 따로 움직이므로 같은 비율로 맞춰 주세요(어긋나면 앱은 SOC를 믿습니다). 왼쪽 메뉴의 **시연** 화면에 차량 연결 상태와 들어오는 값(SOC·주행거리·충전 신호·위치), 시연 버튼이 있습니다. debug 빌드는 항상 보이고, release 빌드는 왼쪽 메뉴 맨 아래 버전 글자를 5번 누르면 나타납니다.

**A. 아파트 야간 충전 — 앱이 꺼져 있어도 기록**
1. 왼쪽 메뉴 **집 충전**에서 아파트 완속 단가 입력(예: 250원/kWh), **차량·계산**에서 배터리 용량 확인
2. Battery SOC 40%로 두고 앱을 열어 상태를 한 번 저장
3. 왼쪽 메뉴 **시연** → **① 시동 끄기** (감시를 멈추고 시동 끈 시각을 8시간 전으로 옮김) → Battery SOC를 90%로 변경 (Odometer는 그대로)
4. **③ 시동 켜기** → 홈 화면에 '아파트 완속 · SOC 40% → 90% · 추정 ○○원' 기록과 '집 충전기가 맞나요?' 확인 카드
5. '네, 집 충전기' → 다음부터 자동

몇 분 사이에 SOC를 크게 올리면 완속으로는 불가능한 속도라 급속으로 판정된다. 그래서 시연 버튼으로 실제 야간처럼 긴 공백을 만든다. 실차에서는 앱 강제 종료·재부팅(BootReceiver)으로도 같은 흐름이 동작한다.

**B. 공용 충전 — 실시간 미터**
1. Gear P, Charge Port Open, Charge Switch On → Battery SOC를 30% → 40% → 50%로 조금씩 올림 (Odometer 그대로)
2. 홈 화면 상단 '충전 중' 카드에서 지금까지 금액·목표 SOC까지 시간 확인
3. SOC를 3분 동안 그대로 두면 충전 종료로 보고 기록 생성 → '영수증 입력'으로 실제 금액 확정

**C. 관리비 고지서 정산**
- 홈 → '관리비 고지서로 아파트 충전 정산' → 월 선택 → 고지서 금액 입력 → 그달 아파트 기록 합계가 고지서와 일치

**E. 말로 단가 입력**
1. 처음 가는 충전소 충전을 마치면 앱이 짐작한 단가(공시가, 또는 같은 사업자 다른 충전소 단가)로 "○○점 단가를 SK일렉링크 공시 요금 391원으로 할까요?"라고 묻는다 (에뮬레이터 마이크 접근 설정 필요). 짐작할 단가가 없으면 "○○ 단가를 말씀해 주세요"
2. "응" → 그 단가로 저장 / "삼백팔십오 원" → "SK일렉링크 ○○점 100에서 200킬로와트 충전기, 킬로와트시당 385원으로 저장할까요?" → "응" → 저장, 다음부터 자동 (출력 구간은 차가 알아서 묻지 않음)
3. 설정 → SK일렉링크 → "말로 입력" → "급속 350원" → 구간마다 요금이 달라 "충전기 출력이 몇 킬로와트인가요?" → "백" → 100~200kW 칸에만 350원
4. "3850원"처럼 범위(100~1,000원) 밖이면 다시 묻는다. 설정 → "아파트 단가 말로 입력"도 같은 흐름

**F. 같은 사업자 다른 충전소 — "지난번처럼 ○○원으로 할까요?"**
1. 시연 → 예시 기록 넣기 → 홈의 'SK일렉링크 판교점' 카드에서 '말로 고치기' → "사백이십 원" → "응" (판교점 100~200kW 420원 저장)
2. 시연 → 다른 SK 충전소 충전 넣기 → 'SK일렉링크 시청점' 카드: "지난번 SK일렉링크 판교점(확인한 날) 단가 420원으로 계산했어요" → '맞아요 · 420원' 한 번이면 시청점 단가로 저장
3. 아파트 단가를 바꿔 보면(집 충전 → 저장) 지난 아파트 기록은 그대로 두고, 금액이 달라질 기록이 있으면 "그대로 두기 / 잘못 입력했어요" 중에 고른다

**시연용 기록** — 시연 → '시연용 석 달 기록 (지우고 새로)': 8월부터 어젯밤까지 아파트 완속·회사 근처 급속·휴게소 초급속·집 근처 공용 급속 21건을 실제 주행처럼(전비 약 5.2km/kWh) 만들고, 공용 충전은 영수증, 지난달까지 아파트 충전은 관리비 고지서로 확정한다. 충전소·충전소 확인 단가도 지워 시연 흐름이 늘 같다. 통계(아낀 돈·월별·충전소별 '가장 저렴')와 월간 브리핑이 실제처럼 보인다.

**G. 가는 충전소 예상 충전비 · 음성 안내**
1. F를 마친 상태(시청점 단가 확인됨)에서 시연 → '시청점으로 안내 중 (100kW · 30→80%)'
2. 홈 상단 '가는 충전소 · SK일렉링크 시청점 — 약 16,256원 · 30% → 80% · 약 40.6kWh · 400원/kWh (이 충전소 확인 단가)' 카드가 뜨고 4초 뒤 읽어 준다(실차에서는 내비 목적지를 충전소로 정하면 같은 흐름)
2-1. 충전까지 이어서(시연 영상 ②~④): 시연 → '판교점으로 안내 중 (100kW · 30→80%)' → 홈에 판교점 예상 충전비 카드와 음성 → Virtual Console에서 Battery SOC(와 Battery Energy)를 1%씩 올리면 홈에 '충전 중' 실시간 미터(지금까지 금액·충전량·목표까지 남은 금액) → Odometer를 조금 올려 출발하면(또는 SOC가 3분간 그대로면) 'SK일렉링크 판교점' 충전으로 기록하고 "충전이 끝났어요. ○킬로와트시, 약 ○원으로 기록했어요"라고 읽어 준다. 에뮬레이터에서는 Virtual Console의 Charge Port·Charge Switch를 바꾸면 시스템이 다시 시작될 수 있어 SOC만 올린다
3. 시연 → '지난달 브리핑 듣기' → "10월 충전비는 ○번에 ○원이에요. 9월보다 ○원 적어요. 내연기관차보다 ○원 아꼈어요."
4. 통계 → 충전소별 → '길안내'(또는 시연 → '자주 가는 충전소로 실제 길안내') → 에뮬레이터 내비가 그 충전소까지 경로를 계산하고 안내를 시작한다
5. 실제 내비 연동: 에뮬레이터 내비 → 검색 → '충전소' → 결과의 경로 버튼 → '목적지로' → 앱 홈에 '가는 충전소 · ○○'가 뜬다(NaviHelper onDrivingInfo). 배터리가 목표보다 높으면 "지금 배터리가 85%라 목표 80%까지 채울 필요가 없어요", Virtual Console에서 SOC를 30%로 낮추면 예상 금액까지 보인다

**H. 자주 가는 곳 이름 붙이기**
1. 시연 → '회사 주차장 완속 충전 (7kW)' → 홈에 '회사 지하주차장 충전기' 확인 카드
2. 카드의 '이름 붙이기' → '회사' 칩 → 저장 → 카드·기록·통계에 '회사'로 보인다
3. 다음에 같은 자리에서 충전하면 처음부터 '회사'로 기록된다

배터리 용량: 에뮬레이터는 차량 용량을 179.6kWh로 알려 준다. 차량·계산에 77.4처럼 용량을 넣으면 그 값이 차량 값보다 우선한다(비우면 차량 값).

**D. 주행 중**

## 개인정보

- 모든 기록은 차량 내부 저장소에만 저장되며 서버로 전송하지 않습니다.
- 위치는 집 충전기 인식과 충전소 구분(충전소별 단가)에만 사용합니다. 저장하는 좌표는 설정한 집 위치 1곳과 실제로 충전한 공용 충전소 위치뿐이며, 주행 경로는 남기지 않습니다.
- 이름 없는 충전소의 주소 표시에 기기 주소 변환 서비스(Android Geocoder)를 쓰며, 이때 충전소 좌표가 기기 위치 서비스 제공자에게 전달될 수 있습니다. 주소 변환이 안 되면 좌표와 사업자로만 표시합니다.
- 설정 → 충전소 목록에서 충전소별 단가·좌표를 보고 이름 변경·삭제할 수 있습니다.
- 공공데이터(선택 기능)는 시·도 코드만 보내 그 시·도 충전소 목록을 받고, 내 충전소 주변(500m)만 기기에 남깁니다. 내 위치·충전 기록은 보내지 않습니다. 오피넷은 전국 평균 유가만 받습니다.
- 공공데이터·오피넷 키는 `local.properties`(저장소 제외)에만 두고, 키가 없으면 그 기능은 꺼진 채로 동작합니다.
- 길안내는 기록에 남은 충전소 좌표를 차 안의 내비게이션에만 넘깁니다.
